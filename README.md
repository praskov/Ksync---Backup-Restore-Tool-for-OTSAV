# KSYNC - BACKUP & RESTORE TOOL FOR OTSAV

Software : Ksync
Developer: Praskov

## ABOUT

Ksync is a simple Backup & Restore tool for OtsAV.

## IMPORTANT

This is NOT an installer.

Before running Ksync, make sure you have the
.NET 8 Windows Desktop Runtime (x64) installed.

If it is not installed, download it here:

https://builds.dotnet.microsoft.com/dotnet/WindowsDesktop/8.0.30/windowsdesktop-runtime-8.0.30-win-x64.exe

## REQUIREMENTS

* Windows
* .NET 8 Windows Desktop Runtime (x64)
* OtsAV

## RUNNING KSYNC

1. Install the required .NET 8 Windows Desktop Runtime.
2. Extract the Ksync files.
3. Run Ksync.exe.

No installer is required.
